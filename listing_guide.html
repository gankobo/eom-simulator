1. このページで確かめられること

3D 回転は非可換であり、平面的な直感が通じません。このページは 2 つの法則を数式と動きで対応させます。

  • Listing 則：正常な固視眼位の「ねじれ（回旋）」は視線方向ごとに一意に定まり、回転ベクトルは 1 枚の平面（Listing 面）に乗る。
  • half‑angle 則：固視を保つ運動の角速度軸は、眼位の偏心角 E の半分（E/2）だけ Listing 面から傾く。これが「偽の回旋」を生まない仕組み。

2. 座標系・回転ベクトル・Listing 面

右手系。第一眼位の視軸 = +X、+Y 鼻側、+Z 上方。眼位は単位クォータニオン q。

回転ベクトル（Rodrigues 表現）

回転角 θ・回転軸 n̂ の姿勢を、次のベクトルで表します（src/core/kinematics/rotvec.ts）：

rotvec = tan(θ/2)·n̂ = ( q_x/q_w , q_y/q_w , q_z/q_w )

回転軸の向きをそのまま指す量なので、「回転軸がどの平面に乗るか」を調べるのに適しています。

Listing 面

第一眼位の視軸を法線とする平面、すなわち YZ 平面（法線 +X）を Listing 面と定義します。 「固視眼位の回転ベクトルが Listing 面に乗る（＝ X 成分 = 0）」ことが Listing 則の数学的表現です。3D では水色の円板で表示されます。

3. Listing 則（固視眼位の幾何）

Listing 則に従う固視眼位を、第一眼位（+X）から目標視線方向への「最短弧回転」として構成します （listingQuat／src/core/kinematics/listing.ts）： 

目標視線  d = R(q_gaze)·x̂
q_Listing = shortestArc( x̂ , d )      // 回転軸 = x̂ × d

x̂ × d は必ず X 成分が 0、つまり回転軸は Listing 面（YZ）内にあります。よって回転ベクトルの X 成分も 0 となり、Listing 則が満たされます。 偏心角は 

E = arccos( x̂ · d )     // 第一眼位と現在視線のなす角（度）

で与えられます。

注意：Listing 則の眼位は「Fick 座標で回旋 0」ではありません。斜め眼位では Fick で測った眼球回旋（torsion）は非ゼロになります。 これは誤差ではなく、Listing 則が要求する視線ごとに一意な回旋そのものです（画面の「12時の傾き」がこれを示します）。

4. half-angle 則（角速度軸の傾き）

2 眼位 q₁ → q₂ の運動の角速度軸（固定系）は ω ∝ vec(q₂ ⊗ q₁⁻¹) で求まります（velocityAxis）。 Listing 則を保つ固視運動では、この角速度軸が Listing 面から傾く角度が 

tilt = arcsin( |ω_x| )  ≈  E / 2

となります（velocityAxisTilt）。これが half‑angle 則です。「位置」は Listing 面に乗る（傾き 0）のに対し、「速度軸」はその半分だけ面から外れる、という位置と速度の幾何的な関係です。 3D では、面内の緑の位置ベクトルに対し、橙の角速度軸が E/2 だけ立ち上がって見えます。

5. 数値欄の定義（数式との対応）

右パネル「数値（数式との対応）」の各行は次を表示します。

偏心角 Earccos(x̂·d)第一眼位からの視線のズレ角。
予測 E / 2E/2half‑angle 則の理論予測値。

6. 「到達のしかた比べ」3パスの意味

同じ目標眼位へ 3 通りの動かし方で到達させ、着地時の 12 時（回旋）を見比べます。3D 回転の非可換性を体感するのが狙いです。

パス構成（実装）着地
① 1回転で到達 最短弧を 1 本の軸で補間
slerp(I, q_Listing, s)		 正解に一致。軸は Listing 面内、偽の回旋なし。
② half-angle 2段階 各段が Listing 則を保つ
listingQuat(h·t,0) → listingQuat(h,v·t)		 正解に一致。第2段の軸が E/2 傾く（half‑angle）ため回旋が残らない。
③ 半角なし 素朴2段階 頭部固定軸の素朴合成（Fick）
gazeQuat(h·t,0) → gazeQuat(h,v·t)		 12 時がズレて着地＝偽の回旋。half‑angle 補正がないため。

①②は同じ回旋（正解）に着地し、③だけがズレます。結論：頭部固定軸で素朴に回転を合成すると眼位依存の偽の回旋が蓄積する。 Listing 則／half‑angle 則は、これを防いで視線ごとに回旋を一意に保つ脳と眼球運動系の解です。

7. 3Dの凡例

  • 水色の面：Listing 面（YZ）。固視眼位の回転ベクトルはここに乗る。
  • 緑の矢印：位置の回転ベクトル（第一眼位→現在）。面内にある。
  • 橙の矢印：角速度軸（固視運動）。面から E/2 傾く＝half‑angle。
  • 赤い指針：角膜前面の時計。12 時の傾き＝眼球の回旋。数値欄に外旋/内旋を併記。
  • 薄い指針：正解（目標 Listing 姿勢）の 12 時。各パスがここに収束するか見る。
  • 紫／金の矢印：到達比べで進行中の段の回転軸（紫＝第1段、金＝第2段）。

8. 臨床的・生理学的な位置づけ

Listing 則はサッカードや固視といった頭部静止時の正常な 3D 眼位則で、視線方向ごとに眼球回旋を一意に定めます （前庭性眼球運動などでは系統的に修正されます）。half‑angle 則はその速度領域での署名です。

機序としては、直筋の眼窩プーリーが力学的に half‑angle を実装するという「能動プーリー仮説（active pulley hypothesis）」が提唱されています。 本デモの③は「この仕組みが無ければどうなるか（偽の回旋）」を示すもので、実際の眼では脳とプーリーが①②の挙動を実現します。 斜筋麻痺などで観察される回旋偏位を理解するための幾何学的な枠組みとして役立ちますが、本ページはあくまで教育デモであり、個別症例の予測には用いません。

9. 限界

  • 理想化した幾何モデル（雑音・個人差・前庭修正・調節性輻輳などは含まない）。
  • 能動プーリーの力学そのものは実装しておらず、half‑angle は幾何として提示している。
  • 数値は小数で丸め表示。残差が厳密に 0 でなく微小値に見えることがある。
