1. 一言でいうと（数値の定義）

作用表の 回旋・上下転・水平 の3値は、その筋を単独で収縮させたときに眼球が回転しようとする「瞬間回転軸」の向きを、 眼球自身の3つの軸（視軸まわり＝回旋、横軸まわり＝上下転、垂直軸まわり＝水平）に分解した方向余弦です。

  • 各値は −1〜+1 の無次元量。絶対値が1に近いほど、その眼球軸に回転軸がよく揃っている（＝その方向の純粋な作用）。0（画面では「—」）はその軸まわりにほぼ作用しない。
  • 符号は臨床の向きを表す（次節）。表示は 0.85 外旋 のように大きさ＋向きの語で示す。
  • これは古典的な 主作用 / 副作用 / 第三作用（primary/secondary/tertiary action）の分解を、定量化したものに相当します。
重要な性質：これは回転軸の向き（単位ベクトル）であって、力・張力・トルク・回転量（度数）ではありません。 各行は内部で正規化されているため、筋どうしの数値の大小を「どちらが強いか」と読むことはできません（§5）。

2. 座標系と符号規約

計算はすべて右眼正準系（右手系, 単位 mm, 眼球半径 R = 12 mm）で行います。

軸正方向意味
+X前方第一眼位の視軸（line of sight）
+Y鼻側（nasal）水平軸
+Z上方（superior）垂直軸

眼位は単位クォータニオン q で表し、Fick 角から次の順（intrinsic Z→Y→X）で合成します （src/core/kinematics/fick.ts）： 

q(h, v, τ) = q_Z(h) · q_Y(−v) · q_X(τ)
角回転軸符号規約
水平 hZ+ 内転（adduction） / − 外転（abduction）
垂直 vY（−v で合成）+ 上転（supraduction） / − 下転（infraduction）
回旋 τX+ 外旋（excycloduction） / − 内旋（incycloduction）

3. 作用ベクトルの定義（表の3列）

眼位 q における眼球固有の3軸（回転行列 R(q) の各列）を 

l = R(q)·x̂   （視軸）
t = R(q)·ŷ   （横軸）
u = R(q)·ẑ   （垂直軸）

とし、筋の眼窩系での単位回旋軸を a(q) とすると、表の3値は a を各眼球軸へ射影した内積です （src/core/model/action.ts）： 

回旋  tor = a · l      （視軸まわり）  + 外旋 / − 内旋
上下転 ver = a · t      （横軸まわり）  + 下転 / − 上転
水平  hor = a · u      （垂直軸まわり）+ 内転 / − 外転

（実装ではコード上の変数名が l, t, v ですが、本文では垂直角 v との混同を避けるため垂直軸を u と表記しています。）

内積 a·l は「回転軸 a と視軸 l のなす角の余弦」であり、1 = 軸が完全に一致（その軸まわりの純回転）、 0 = 直交（その軸まわりには作用しない）を意味します。眼位 q が変われば l,t,u も a（Tier1）も変わるため、 同じ筋でも眼位ごとに3値は変化します。これが本シミュレータの主眼です。

4. なぜ行の和は1でなく、二乗和が1になるのか

a は単位ベクトル、{l, t, u} は正規直交基底です。したがって3値は a の直交3方向への成分（方向余弦）であり、 

tor² + ver² + hor² = ‖a‖² = 1

が成り立ちます。単純な和が1になる量ではありません（分け前・確率ではない）。 例：0.8 と 0.6 は和 1.4 ですが、0.8² + 0.6² = 1.00。方位磁針の針を東西・南北成分に分けるのと同じで、成分どうしを足すことに意味はありません。

列（縦）についても、各筋が独立に持つ作用を並べただけで、合計に意味はありません （複数筋が同じ向きへ同時に働くのは正常です）。表示は小数第2位に丸めるため、二乗和はぴったり 1.00 に見えないことがあります。

5. この数値が「表さない」もの（重要な限界）

臨床解釈で誤読しやすい点を明示します。この数値は幾何学的（運動学的）な回転軸の向きのみを表し、次を含みません：

  • 筋張力・力・トルク：張力やモーメントアーム長は掛かっていません。正規化により大きさ情報は意図的に捨てられています。
  • 回転量（度数）：どれだけ回るかではなく、どの向きに回るかです。
  • 筋間の相対的な強さ：各行が独立に正規化されるため、2つの筋がともに「1.00 内転」でも、それは軸の向きが同じという意味で、トルクが等しいという意味ではありません。
  • 共同運動・拮抗・神経支配：Hering / Sherrington 則、共同筋・拮抗筋の相互作用、length‑tension は反映していません（各筋を単独・等尺的に見た幾何量です）。
要するに、この表は「各筋の作用軸の向き（単位ベクトル）を眼位ごとに示すもの」です。 力ベクトルを張力×モーメントアームで重み付けして合成トルクを出すモデルとは別物であり、本画面では行間・筋間で大きさを足したり比べたりする設計にはなっていません。

6. モデル階層 Tier0 / Tier1 / Tier2 と回旋軸の式

UI の「モデル」で切り替えられる3階層は、回旋軸 a(q) の作り方が異なります。 「3モデル比較」を ON にすると、同じ眼位での3本の作用軸を線種で重ねて表示します （点線=Tier0／破線=Tier1／実線=Tier2）。第一眼位では3本が一致し、眼を偏心させるほど分かれます。

Tier0 — kinematic（教育用ベースライン）

各筋に眼窩固定の単位回旋軸を与えます。眼位に依存しません（src/core/model/kinematic.ts）。

a = normalize(fixedAxis)   // 眼位非依存

第三作用の眼位依存を持たないため、Tier1 との対比用のリファレンスとして残しています。

Tier1 — string model（Robinson 1975 / SQUINT）

付着部 P と機能的起始 Q から、眼位ごとに回旋軸を再計算します （src/core/model/string.ts）： 

P = R(q)·P0            // 付着部（眼球とともに回転して移動）
Q = origin            // 機能的起始（眼窩固定：直筋 pulley / 斜筋 滑車）
a(q) = normalize(P × Q)

眼球中心・起始 Q・付着 P を通る筋の張る平面に直交する軸が P × Q で与えられる、という string model の標準的な帰結です。 眼位で P が動くため軸が回り、第三作用の眼位依存が自然に現れます （例：外転位で上直筋 SR の水平・回旋成分が減衰し、純粋な上転筋に近づく）。

Tier1 の近似：付着点近似で接触弧補正（arc of contact）は未実装、起始 Q は眼窩固定（受動プーリー）。 このため斜め眼位（tertiary gaze）では引っ張り方向の眼位依存が不足します。これを補うのが次の Tier2 です。

Tier2 — active pulley（能動プーリー / half‑angle 則）

実際の直筋は赤道近傍の結合組織プーリー（Tenon 嚢の袖）を通り、これが筋の機能的起始として働きます。 プーリーは眼球運動にあわせて前後へ能動的に移動し（active pulley, Demer ら）、その結果 筋の作用軸が「眼球回転角の半分」だけ回ります。これが half‑angle 則です （src/core/model/pulley.ts）： 

a(q) = R^(1/2)(q) · a₀        // a₀ = 第一眼位の作用軸（= Tier1 の primary = 教科書値）
R^(1/2)(q) = slerp(I, q, 0.5)  // 眼位 q の「半分」の回転

第一眼位（q = I）では R^(1/2) = I なので a = a₀、すなわち §11.1 の教科書の作用分解を厳密に保ちます。 眼を偏心させると作用軸が偏心角の半分だけ傾き、Tier0（傾き 0＝眼窩固定）と「眼球固定（傾き＝偏心角そのもの）」のちょうど中間になります。

なぜ half‑angle が重要か（臨床的意義）
  • 可換性と Listing 則：作用軸が半角で回ることで、眼球運動が実質的に可換（順序によらない）になり、固視眼位が Listing 面に乗ります。脳が眼位ごとの複雑な回旋補正をせずに済む仕組みを、眼窩の結合組織が力学的に担っている、という現代的理解です（half‑angle の可視化ページ）。
  • 古典 23° / 51° の精密化：Tier0/Tier1 が示す「直筋 外転23°・斜筋 内転51° で純粋上下転」は第一眼位の筋平面に基づく近似です。half‑angle 則を入れると偏心視での作用軸が補正されるため、Tier2 では回旋 0 交差の眼位がこの角とは一致しません（バグではなく、より現実に近い帰結）。教育上は Tier0/Tier1 で古典像を、Tier2 で精密像を対比してください。
  • プーリー病態：プーリーの位置異常（pulley heterotopy）や加齢によるずれは、麻痺がなくても A/V パターンや上下・回旋偏位を生みます。「筋の走行を規定するのは付着部だけでない」という視点が診断に効きます。手術では付着部を動かしてもプーリーはほぼ動きません（Clark 2006）。加齢では外直筋–上直筋バンドの脆弱化で外直筋プーリーが下垂し、遠見内斜視（divergence insufficiency）や小さな上下・回旋偏位をきたす sagging eye 症候群 が知られます（Chaudhuri & Demer 2013）。本モデルの座標は健常若年者の集団平均であり、こうした加齢・病態は表しません。
学術的な但し書き（誠実な限界）
  • 係数 k = 0.5 は理想値です。half‑angle 則は「固視眼位が Listing 面に乗る」ための幾何学的必然として位置領域では厳密に 0.5 ですが、実測の傾き係数は方向・個体・運動種で幅があります。衝動性運動（サッカード）では水平で約 0.5、垂直で約 0.35 程度、前庭動眼反射（VOR）ではさらに小さく約 0.25（quarter‑angle）です（Tweed & Vilis 1990；Thurtell 2011；Misslisch/Tweed/Hess 1994）。本モデルは視覚誘導運動を代表する 0.5 を採用しています。
  • 「能動」かどうかは今も論争があります。プーリーが機能的起始として存在し、half‑angle と Listing 則を力学的に生むこと自体は広く合意されています（近年は Wei, Mutawak & Demer 2022 の力学シミュレーションが「直筋の走行は眼球回転角の約半分だけ屈曲し、これが Listing 則の実装に必要十分」と裏づけ）。一方、プーリーが眼窩層の収縮で能動的に移動するという能動プーリー説の「強い形」には批判もあります（Miller 2019 と Demer/Clark 2020 の応酬）。本 Tier2 が依拠するのは、論争の少ない受動的なプーリー幾何（half‑angle）だけで、能動的移動の動力学そのものは仮定していません。

直筋のプーリー座標は Clark 2000（IOVS 41:3787–97）Table 2 の実測値（球中心基準）を用い、3D 表示で「眼を動かすとプーリーが動く」様子（実効位置と第一眼位からの移動）を示します。2026 年時点でもこれを置き換える標準データセットは報告されておらず、後続研究もこの座標を前提としています。 斜筋は同論文の対象外のため、滑車（上斜筋）／眼窩底付近（下斜筋、下直筋プーリーと連結）の機能的起始を流用しています。作用軸の計算は 6 筋すべてで上記の half‑angle 則を適用しており、上斜筋は広い強膜付着、下斜筋は連結プーリーによって、いずれも実際に半角的に振る舞うことが知られています（Demer 2003, 2006）。

7. 筋長の列

作用表の 長(mm) は、機能的起始 Q から付着部 P までの直線距離です。

L = ‖P − Q‖

将来の length‑tension（張力–長さ関係）の入力として用いる予定の値で、眼球面に沿う真の経路長（接触弧を含む）ではありません。 現段階では相対変化の目安としてお読みください。

8. 眼位依存の臨界点と検証（§11）

受け入れ基準 §11 を単体テスト化し（npm test で 66 件すべて緑）、それを満たすように解剖パラメータを同定しています。 代表的な検証点は次のとおりです。

§11.2回旋成分の 0 交差：直筋は外転 ≈ 23°、斜筋は内転 ≈ 51°（古典像）。Tier0/1

UI のプリセット「外転23°」「内転51°」は古典の 0 交差の眼位です。Tier0/Tier1 では回旋列が「—」に近づきます。 Tier2 は half‑angle 則により作用軸が半分だけ回るため、同じ眼位でも回旋は完全には消えません（§6 の Tier2 解説を参照）。

9. 左右眼の扱い

単眼の筋作用は左右で臨床的に同一（教科書の作用表は両眼共通）です。本実装は常に右眼正準系で計算し、同じ臨床ラベル（内転／外旋など）で報告することで左眼でも正しくなります。 左眼（OS）に固有なのは (1) 3D 表示の左右鏡映 と (2) 将来の両眼注視フレーム配置 だけで、これらは表示・両眼層が担当します。

補足（設計上の注意）：解剖を世界座標で Y 反転して同じ P × Q に通すと、外積は擬ベクトルのため符号が反転し左内直筋が「外転」になってしまいます。よって物理計算では鏡映しません。

10. 解剖パラメータの出自と暫定性

src/core/data/anatomy.ts の付着部 P0・起始 Q（Tier0/Tier1 が使用）は、輪部からの付着距離（§7.2）・筋平面角（直筋 23° / 斜筋 51°, §7.3）・滑車／起始の象限（§7.5）から構成し、 §11 の作用と 0 交差に一致するよう同定した暫定スターター値です。個々の患者の計測値でも、確定した集団平均値でもありません。

一方、Tier2 のプーリー座標（直筋）は Clark 2000（IOVS 41:3787–97）Table 2 の実測値（健常者 MRI, 球中心基準）を採用しました。各値に source を付記しています。 Tier0/Tier1 の暫定値は古典像との対比のために温存しています。現段階の数値は定性的・教育的にお読みください。

11. 既知の限界と今後の拡張

  • 接触弧補正なし（付着点近似）。→ 接点 T での力作用・経路長を後続で追加。
  • Tier2 の能動プーリーは half‑angle 則を運動学的に実装したもの（結合係数 k=0.5 固定）。係数を可変にする（方向別・運動種別）拡張、プーリーの前後移動そのものの動力学（Kono 2002 の tertiary 実測差）、斜筋プーリーの実測座標への差し替えは今後。
  • 近見（輻輳）時に Listing 面が耳側へ約 1/4 輻輳角だけ傾く挙動（extended Listing 則 / quarter‑angle：Mok 1992；van Rijn & van den Berg 1993）と、VOR での quarter‑angle は、いずれも両眼モデル（P4）や運動モードの切替が前提のため本 Phase では未実装。
  • 単眼の筋作用に関わる分節性神経支配（compartmental innervation：水平直筋が上下分画で別々に制御されうる）は張力入力を要する二次効果で、運動学のみの本モデルでは扱いません（Demer ら 2011）。
  • 力学（張力・length‑tension・平衡）は未実装。本画面は運動学的な作用軸のみ。
  • 両眼・臨床モジュール（麻痺／手術／Hess／Bielschowsky）は将来 Phase。

ロードマップ：P3 active pulley（本 Phase 完了） → P2 平衡ソルバ → P4 両眼 → P5 臨床。
